Understanding Percent Encoding

Percent-encoding is a mechanism for encoding arbitrary data in a Uniform Resource Identifier (URI) using only ASCII characters. Characters like spaces or slashes must be represented as percent blocks (like `%20` or `%2F`) to prevent server routing errors.
