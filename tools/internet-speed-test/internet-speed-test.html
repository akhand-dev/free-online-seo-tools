How Network Speed Tests Work

Internet speed checkers estimate connection parameters by transferring packets between your device and a target file location. Our test measures connection metrics in two distinct stages:

  • Ping (Latency) Test: Performs a series of tiny fetch handshakes to local assets with random queries. The time taken to receive responses indicates round-trip latency in milliseconds (ms). Lower numbers are better.
  • Jitter Test: Computes the deviation or variance between consecutive latency tests. Stable connections have lower jitter.
  • Download Test: Requests a moderately large, cache-bypassed file in the repository (e.g. `tools/qr-code-example.png`, sized 289 KB) in a parallel loop. The test calculates total downloaded megabits per second.

What constitutes a good speed?

Standard household and office bandwidth needs depend on usage profiles:

  • 10 - 25 Mbps: Good for standard web browsing, emailing, and streaming HD videos on one or two devices.
  • 25 - 100 Mbps: Recommended for families and multi-device homes. Smooth 4K video streams and online gaming.
  • 100+ Mbps: Exceptional. Ideal for heavy file downloads, large remote work file transfers, and parallel operations.
